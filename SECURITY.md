# Reporting a vulnerability

Last verified: 2026-10-28 @ 51a7d79

Please do **not** open a public issue for security problems.

Report privately through GitHub's "Report a vulnerability" (Security → Advisories) on this repository. Include the affected version or commit, the steps to reproduce, and the impact. We aim to acknowledge reports within 72 hours and to publish a fix and advisory within 90 days, sooner for actively exploited issues.

The threat model and security rules are in [docs/SECURITY.md](docs/SECURITY.md).
